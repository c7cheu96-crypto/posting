# 블로그 글 채워넣기 (크롬 확장)

GitHub `posting` 저장소에 자동으로 써진 글(post.json)을 네이버 블로그 글쓰기 화면에 채워 넣어요.
저장소가 공개라서 GitHub 로그인이나 토큰은 필요 없어요.

## 설치 (처음 한 번)

1. 이 `chrome-extension` 폴더를 컴퓨터에 받아 둡니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → `chrome-extension` 폴더 선택
5. 퍼즐 아이콘에서 📌 고정

## 사용

1. 네이버 블로그 **글쓰기** 화면을 엽니다.
2. 확장 아이콘 클릭 → 불러올 글 입력 후 **불러오기**
   - `latest` : 오늘 자동으로 써진 글
   - `1026` : `inbox/1026/post.json`
   - 경로 직접 입력도 가능 (예: `posts/2026-11-07/경제용어_리스크오프`)
3. **네이버 에디터에 채워넣기** → 제목, 본문, 사진이 순서대로 들어가요.
4. **태그 복사** → 발행 창의 태그 칸에 붙여넣기
5. 내용을 확인하고 **[발행]**은 직접 눌러 주세요.

## 자동으로 안 들어갈 때

- 글쓰기 화면을 새로고침(F5)하고 다시 시도해 보세요.
- **본문 복사** → 본문에 Ctrl+V, 사진 썸네일을 눌러 복사 → `[사진N]` 자리에 Ctrl+V
